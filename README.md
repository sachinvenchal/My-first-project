#About my project

*I built a data-driven dashboard that analyzes sales, customer ratings, payments, delivery, and seasonal trends across 2016–2018. It highlights top-performing categories (like health_beauty), customer satisfaction gaps, regional sales leaders, and delivery delays.*

*📊 Impact: The dashboard transforms raw retail data into actionable insights — helping businesses optimize inventory, improve logistics, refine product strategies, and align marketing with customer behavior.*
